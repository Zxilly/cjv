# cjv 用户手册

cjv 管理[仓颉](https://cangjie-lang.cn/) SDK，让不同项目使用各自需要的编译器版本。安装后可以直接运行 `cjc`、`cjpm`，由 cjv 选择对应的工具链。

首次使用请从[安装 cjv](installation/index.md)和[快速上手](basic-usage.md)开始。团队项目可提交 [cangjie-sdk.toml](toolchain-file.md) 固定工具链；需要扩展库或其他平台的 SDK 时，查看[组件](concepts/components.md)和[交叉编译](cross-compilation.md)。

完整参数见[命令参考](command-reference.md)。内网镜像、受管终端和离线安装见[企业部署](enterprise/index.md)。
