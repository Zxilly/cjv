# cjv user guide

cjv manages [Cangjie](https://cangjie-lang.cn/) SDKs so each project can use the compiler version it needs. Once installed, you can run `cjc` and `cjpm` directly; cjv selects the toolchain.

Start with [installation](installation/index.md) and [quick start](basic-usage.md). Commit a [cangjie-sdk.toml](toolchain-file.md) to share a project's toolchain selection. See [components](concepts/components.md) for extension libraries and [cross-compilation](cross-compilation.md) for target SDKs.

The [command reference](command-reference.md) lists command options. [Enterprise deployment](enterprise/index.md) covers internal mirrors, managed clients, and offline installation.
